# Project Portfolio · Next.js + Tailwind + CSS

An interactive, modern, high-performance technical portfolio designed to showcase solutions in **Artificial Intelligence**, **Computer Vision**, **MLOps**, and **Software Engineering**. 

Built using **Next.js 14**, **TypeScript**, and **Tailwind CSS**, and optimized for static export and automated deployment on **GitHub Pages**.

---

## Tech Stack

### **Frontend & Framework**
- **Next.js 14** (App Router, Static Export)
- **TypeScript**
- **Tailwind CSS** (Styling & Responsive Design)
- **Lucide React** (Icons)

### **DevOps & Deployment**
- **GitHub Actions** (CI/CD Pipeline)
- **GitHub Pages** (Static Hosting)

---

## Overview

This portfolio centralizes my projects in computer vision, MLOps pipelines, and data processing. It includes interactive modals with performance metrics (KPIs), architecture previews, media previews, and direct links to repositories and live demos.

---

## Key Features

- **Modern & responsive design**: Dark interface with cyan/blue accents, Inter typography, and adaptive layouts.
- **Interactive project modals**: Detailed breakdown of architecture, KPIs, technical deliverables, and interface images.
- **Dynamic & relative paths**: Optimized asset and image management that prevents 404 errors in GitHub Pages subdirectories.
- **Functional contact form**: Direct integration with **Formspree** for receiving messages without a custom backend.
- **SEO optimization**: Complete configuration of Open Graph metadata, local favicons, and social meta tags.
